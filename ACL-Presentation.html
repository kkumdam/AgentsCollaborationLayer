01 — 문제 인식

단일 에이전트의 한계,
그리고 자연어의 비효율

현재 대부분의 AI 코딩 어시스턴트는 하나의 에이전트가 모든 작업을 순차적으로 처리합니다. 에이전트 간 소통은 자연어에 의존하며, 이는 규모가 커질수록 치명적인 병목이 됩니다.

⚡
O(n²) 컨텍스트 폭발
자연어(NL) 핸드오프는 매 단계마다 이전 대화 전체를 재전송합니다. 10단계 파이프라인에서 누적 토큰은 48,500개에 달합니다.
🎯
신뢰성 급락
NL 기반 파이프라인의 완료율은 단계가 깊어질수록 급격히 하락합니다. 20단계에서 완료율은 30%까지 떨어집니다.
💸
비용 비효율
자유형식 응답은 서론, 부연 설명, 마크다운 포매팅 등 불필요한 토큰을 2~3배 더 생성하여 비용을 낭비합니다.
"에이전트가 많아질수록 자연어 통신의 비용은 기하급수적으로 증가하지만,
작업의 품질은 반비례하여 저하됩니다."

02 — ACL 소개

Agent Collaboration Layer

ACL은 에이전트 간 비언어적(non-linguistic) 통신 및 오케스트레이션 런타임입니다. 자연어 프롬프트 대신 타입 기반 ActionPacket, 상태 전이, 아티팩트 참조로 협업합니다.

📦
ActionPacket
모든 작업 요청은 ~180 bytes (~45 tokens) 크기의 타입화된 패킷으로 구조화됩니다. 파이프라인 깊이와 무관하게 상수 크기를 유지합니다.

{ packet_id, intent, constraints, output_schema, priority }
🔄
State Machine
각 태스크는 결정론적 상태 머신으로 관리됩니다.

PENDING → CLAIMED → RUNNING → DONE | FAILED

각 전이마다 이벤트가 발행되고, 의존성 그래프(DAG)가 자동으로 해소됩니다.
🗄️
Artifact Store
모든 산출물은 SHA-256 해시 기반 content-addressable 저장소에 보관됩니다. artifact://type/hash URI로 참조하여 데이터 재전송을 방지합니다.
🛡️
Policy Engine
스폰 제한, 예산 한도(USD), TTL, 도구 접근 제어를 프로토콜 수준에서 관리합니다. 정책에 의해 비용 폭주를 원천 차단하고, 에이전트 간 권한을 세밀하게 제어합니다.

🔬
Gemini
리서치와 문서화에 탁월

Intent Routing Table

code_review → Claude (fallback: Gemini)
bug_analysis → Claude (fallback: Gemini → Codex)
documentation → Gemini (fallback: Claude)
Tie-breaking: trust_score > latency > cost

09 — 기대 효과

ACL이 가져올
근본적인 변화

💰
비용 혁신
프로덕션 규모(10K 파이프라인/일)에서 연간 $207K 절감. 고비용 모델(Claude Opus)에서는 1K 핸드오프당 $175.95 절감. 규모가 커질수록 O(n) vs O(n²) 복잡도 차이가 기하급수적 절감으로 이어집니다.
🚀
속도 향상
JSON 스키마 강제로 59% 레이턴시 절감. 불필요한 서론과 부연 설명을 제거하여 LLM이 구조화된 데이터만 생성합니다. DAG 기반 병렬 실행으로 전체 파이프라인 완료 시간도 대폭 단축됩니다.
🛡️
안정성 보장
20단계 파이프라인에서 ACL 93% vs NL 30% 완료율. Typed state transitions으로 포맷 드리프트를 제거하고, 결정론적 재시도 메커니즘으로 에러 캐스케이드를 방지합니다.
🔍
완전한 관측성
모든 에이전트 간 통신이 typed event stream으로 기록됩니다. 태스크 상태, 아티팩트 흐름, 비용 추적이 프로토콜 수준에서 보장되어 디버깅과 감사가 즉각적으로 가능합니다.
